# 新秩序：芸芸众生

基于“80亿分之1”的人生模拟设计，制作的中文 TNO 同人网页游戏。1962 年 1 月以 18 岁青年身份开局，逐月经历十年，在 1972 年 1 月结算；健康归零会提前结束。无需后端、账号或联网资源。

## 运行

直接用现代浏览器打开 [`1in8b-source/index.html`](1in8b-source/index.html)，或在仓库根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 <http://127.0.0.1:8765/1in8b-source/index.html>。同一浏览器在不同地址（包括 file://、localhost 与 127.0.0.1）下的存档相互独立。

## 游戏

- 八个起始地区：美国、德国、日本、中国、广东、托木斯克、鄂木斯克、伊尔库茨克；可以指定或随机出身。
- 从 1962 年 1 月到 1971 年 12 月按月生活。重大世界事件以独立电报通报，随机个人遭遇以生活弹窗呈现，阅读即可继续；部分月份只是平常日子。只有重要的生活抉择才提供选项，每月最多一个决定。自动推进在通报阅读后恢复，遇到决定暂停，切换页面或后台时停止。
- 每月有 2 次自由行动，可安排零工、进修、休养、陪伴家人或整理证件避险。买入、卖出投资各使用 1 次行动，事件选择不占次数；剩余次数不结转。
- 选择会改变职业、居住地区与长期经历，开启或关闭后续路径。部分选项要求资金、教育或先前经历；界面会说明未满足的条件。个人选择产生的追踪事件最早在后续月份出现。
- 共 320 条内容：60 条无需选择的个人遭遇、16 条世界通报、244 条可能遇见的生活抉择。原来的 120 条月度故事保留年月窗口，作为随机机会出现；每局不会全部经历。
- 美国、德国、日本各两类路线，俄罗斯三类统一走向；世界路线由开局种子决定，个人选择不直接决定国家路线。
- 世界消息在指定月份抵达，新闻对所有地区可见，直接数值影响按事件指定的居住地区生效。每次选择、行动、交易与月结都留下日期和属性变化记录。
- 1972 年 1 月生成人生阶段总结；结局和历次记录在浏览器本地保存。相同命运编号也能保留不同选择的结局，支持单独查看、删除和导出 JSON 档案。

## 像素街区

主界面展示原创代码绘制的像素街区。八个出身地区具有不同的配色与环境；职业改变工作场所，资金及住房经历影响住处，家庭与孩子出现在街景中，季节、昼夜、健康与政治风险也改变画面。点击家、工场、街坊和广播可查看近况或安排生活。像素动画不消耗模拟随机数，尊重系统减少动态效果的设置。

人物详情、账本和投资可以展开查看，事件内容通过弹窗呈现。弹窗可以使用键盘操作；普通遭遇只需阅读，重要选择可以暂时收起，准备好资金后再回应。

## 数值与月度收支

可用资金以“资金点”计量，可以超过 100；健康、教育、家庭关系和政治风险保持 0—100。所有数值都是游戏参数，不代表现实人口、收入或金融统计。

| 数值 | 实际作用 |
| --- | --- |
| 健康 | 低于 30 时月收入减少 4、医疗开支增加 3；归零立即结算。休养可恢复健康。 |
| 可用资金 | 支付生活费、事件费用、进修与休养费用，买入投资后变为持仓。资金不足会锁定付费选项；基本生活费不足会损伤健康。 |
| 教育 | 达到 35 时月收入增加 1，达到 60 时增加 3；部分技术与职业选择另有门槛。 |
| 家庭关系 | 达到 65 时月开支减少 2；低于 30 时开支增加 1，并额外损失健康。每月会自然疏远，可以主动陪伴。 |
| 政治风险 | 越低越好；达到 70 时收入减少 2、开支增加 2，每月有机会因盘查损失资金与健康。 |

月收入还受职业和已发生的世界局势影响，开支受取暖季、政策、动员和燃料价格影响。界面显示预计月收入、生活开支、净结余及各项修正。推进月份时结算刚结束月份的收支、投资付息和市场涨跌，随后进入下一月并接收当月新闻；最近月结会展示实际净变化。

## 投资与储蓄

可选择互助储蓄、地方建设债券和工业企业股份。储蓄每份 5 资金点，报价固定，每月每份付息 0.01；建设债券每月每份付息 0.02，报价会波动；工业股份没有固定分红，价格涨跌幅度更大，银行与燃料危机还会传入市场。

买入扣除资金并增加持有份数，卖出按当前报价收回资金；界面分别显示可用资金、持仓市值和合计资产。不能借款买入或卖出没有持有的份数。债券和股份可能亏损，保留生活费与休养费用也是每月决策的一部分。这些规则服务于虚构世界中的生活取舍。

## 文件与开发

- `1in8b-source/index.html`：本版中文入口，依次载入普通脚本，无需模块服务或构建工具。
- `1in8b-source/tno/data.js`：地区、路线与中文事件；`SOURCES.md` 记录资料基准与改编边界。
- `1in8b-source/tno/engine.js`：确定性随机、月度推进、事件分支、行动、收支、市场、结局和状态校验。也可通过 CommonJS 载入用于测试。
- `1in8b-source/tno/scene.js`：原创 SVG 像素街景与状态映射，提供 `TNO_SCENE.render / model`。
- `1in8b-source/tno/app.js`、`style.css`、`emblem.svg`：弹窗、时间控制、界面、本地存储和本地视觉资源。
- `1in8b-source/tno/tests/engine.test.cjs`：无依赖的 Node.js 行为测试，覆盖 120 月进程、八地区安全路线、随机人生、分支延迟、数值作用、投资和存档校验。
- `1in8b-source/tno/tests/app.test.cjs`：使用最小 DOM 环境验证界面操作接线、v3 保存、旧存档迁移与保留；视觉布局需另在浏览器检查。

运行测试（Node.js 18 或更新版本）：

```powershell
node --test 1in8b-source/tno/tests/engine.test.cjs 1in8b-source/tno/tests/app.test.cjs
```

对外数据接口为 `TNO_DATA`。`TNO_ENGINE` 提供：

- `create / advance / choose / event / eligible / summary / validate`：开局、推进、事件选择、查询与校验。
- `notice(state) / dismiss(state)`：读取队首通报和确认阅读。事件效果在发生时结算，确认阅读不重复施加。
- `choiceStatus(state, index)`：选项是否可用及原因。
- `inspect(state)`：预计收支、修正、属性说明、持仓、资产合计及剩余行动。
- `act(state, id) / actionStatus(state, id)`：行动及其可用条件，id 为 `work / study / rest / family / caution`。
- `trade(state, assetId, side, quantity = 1) / tradeStatus(...)`：交易与检查；资产为 `savings / bonds / industry`，方向为 `buy / sell`。
- `migrate(oldV1OrV2)`：显式升级年度制或上一版月度制状态，失败返回 `null`，不修改输入。

引擎仅使用状态中的随机数生成器，市场也使用相同随机源；JSON 往返保存后可继续相同世界线。状态包含 `year / month / elapsedMonths`，以及持仓、报价、当月已用行动和最近月结。状态的 `inbox` 保存未读通报，`incidentDates` 记录个人遭遇的冷却月份，JSON 保存能恢复未读弹窗。`incidents` 为无需选择的客观遭遇，可以配置地区、月份与最短重现间隔；`events` 为需要决定的机会库，其中月度故事保留唯一年月窗口。

## 存档升级

当前存档命名空间是 `tno.everyday.v3`，格式为 `{ version: 3, current, records }`。没有 v3 时，优先尝试迁移 `tno.everyday.v2`，其次是 `tno.everyday.v1`；升级结果另存 v3，原存储键作为备份完整保留。新旧存档中的世界新闻不会在升级时重复施加效果。

v2 的年月、资金、持仓、报价、随机数状态和待处理决定继续有效。v1 的旧历史补记对应年份 1 月，资金承接原经济状况，新增持仓为零。游戏仍不读取或覆盖原网站记录。

新增内容请使用唯一编号和合法地区/路线引用。世界通报需有年月，个人遭遇需有正文和效果，重要抉择需有可行选项；新增条件与效果时同步扩展引擎及行为测试。
