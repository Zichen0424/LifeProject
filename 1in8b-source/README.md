# 80亿分之1：公开前端源码存档

来源：https://1in8b.life/zh-hans/
抓取日期：2026-10-21（Asia/Shanghai）
页面版本：v0.7.94 测试版

## 文件

- `index.html`：本地单文件版。内嵌原站主 JavaScript 和字体样式，保留原页面自带样式。双击即可打开，也可以用下方的本地服务器。
- `original.html`：服务器返回的原始 HTML，未改写。它引用的 `/a/`、`/fonts/` 等绝对路径需要原站环境。
- `assets/zh-hans.21693a37a9.js`：下载的原始主程序，包含游戏逻辑、统计数据、翻译、地图绘制等。
- `assets/fonts.css`：下载的原始字体样式。
- `capture.json`：来源、文件大小和 SHA-256 校验值。

## 本地运行

双击 `index.html`，或在此目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开：http://127.0.0.1:8765/index.html

## 依赖与边界

- 单文件版内嵌了页面和主要游戏脚本；字体文件、网站图标仍从原站加载。离线时使用系统备用字体。
- 保留原站文字、样式和前端逻辑；本地版仅内嵌资源并将 HTML 的站内链接及字体地址补全。
- 多语言、统计详情、关于、隐私等链接跳转原网站；未批量下载其他页面。
- 追思馆、社区、云端记录、通行证等调用 `/api/*`。本地文件或静态服务器不提供这些接口，因此这些在线功能不能通过此存档恢复。
- 没有抓取私人数据，没有执行发帖、支付或修改原站数据的操作。后端程序和数据库无法从公开 HTML 中获取。
- 本地记录由原程序使用浏览器存储保存，与原站记录分开。
